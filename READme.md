# Tugas-2-IF4073-Interpretasi-dan-Pengolahan-Citra

Tugas 2 IF4073 Interpretasi dan Pengolahan Citra

## How to use

- Open your MATLAB and change the current directory to this folder
- Run `tugas2PCDmain.mlapp`
- You will see the GUI window, click the `Run` button
- The GUI window will appear
- Choose the enhancement method you want to use
- Choose the enhancement parameter
- Choose the image you want to enhance
- Click the `Submit` button
- The enhanced image will be shown in the figure format
